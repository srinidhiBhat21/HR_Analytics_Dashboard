# HR Analytics Dashboard | Power BI

## 📌 Project Overview

This project focuses on analyzing employee and workforce data using Microsoft Power BI. The objective is to transform raw HR data into meaningful insights through data cleaning, data modeling, KPI development, and interactive visualizations.

The dashboard helps explore workforce composition, department-wise distribution, employee satisfaction, monthly income, work-life balance, training frequency, and other HR-related indicators.

##  Project Objectives

- Analyze employee distribution across departments and countries.
- Understand workforce composition by grade and employment type.
- Explore monthly income patterns.
- Examine job satisfaction and work-life balance ratings.
- Analyze company environment ratings and training frequency.
- Present HR metrics through an interactive dashboard.
- Develop skills in data modeling, DAX, and business intelligence.

##  Tools and Technologies

- **Microsoft Power BI** — dashboard development and visualization
- **Power Query** — data cleaning and transformation
- **DAX** — measures and calculations
- **Microsoft Excel** — department lookup data
- **CSV** — employee dataset


##  Dataset Overview

The project uses an employee dataset containing **1,480 records and 16 columns**, along with a department lookup file containing department IDs and names.

The dataset includes fields such as:

- Employee ID
- Employee gender
- Marital status
- Department ID
- Employee grade
- Job satisfaction
- Monthly income
- Age
- Job type
- Hire date
- Company environment rating
- Training frequency
- Work-life balance
- Country


##  Analysis Areas
